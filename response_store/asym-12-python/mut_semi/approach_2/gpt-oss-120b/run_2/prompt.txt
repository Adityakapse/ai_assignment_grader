def f(a):
    n = len(a)
    s = 0
    length = 1
    while length <= n:
        for j in range(length):
            s += a[j]
        length = length * 2
    t = g(a)
    return s + t

def g(a):
    n = len(a)
    t = 0
    for i in range(n):
        t += a[i]
    return t

SAMPLE SOLUTION:
Let N be the length of array a.

Method f
Part A: the initialisations of n, s and len - constant time.
Part B (nested loops): the outer variable len takes the values 1, 2, 4, ..., up to N; the inner loop runs len times.
Part C: t = g(a); return s + t - one call to g plus a constant-time return.

Parts A and the return in Part C are Theta(1).

Part B (nested loops):
- Iterations: the inner loop runs len times where len = 1, 2, 4, ..., 2^floor(log2 N). The total number of inner iterations is 1 + 2 + 4 + ... + 2^floor(log2 N) < 2N = Theta(N). This is a geometric series dominated by its largest term, so the total is Theta(N), NOT Theta(N log N).
- Cost per iteration: Theta(1) - one array read and one += assignment.
- Total cost of Part B: Theta(N) x Theta(1) = Theta(N).

Part C:
- The call g(a) costs Theta(N) (see g below); the addition and return are Theta(1).
- Total cost of Part C: Theta(N).

Overall running time of f:
Theta(1) + Theta(N) (Part B) + Theta(N) (Part C) = Theta(N).

Method g
Part D: the initialisations of n and t - constant time.
Part E (for loop): one linear pass over a.
Part F: return t - constant time.

Parts D and F are Theta(1).

Part E:
- Iterations: i runs from 0 to N-1, giving Theta(N) iterations.
- Cost per iteration: Theta(1) - one array read and one += assignment.
- Total cost of Part E: Theta(N) x Theta(1) = Theta(N).

Overall running time of g:
Theta(1) + Theta(N) + Theta(1) = Theta(N).

STUDENT SOLUTION:
f has a doubling outer loop with an inner loop and then calls g. The setup statements are constant.

The loop in f runs about N iterations in total (N is the length of array a). Each pass does an array read and an addition, all Theta(1) simple operations, so f's own loop work is Theta(N).

The call to g afterwards adds some more cost on top.

g uses a single for loop that runs Theta(N) times. Every iteration does an array read and an addition, all Theta(1), so the loop is Theta(N) x Theta(1) = Theta(N).

Putting it together, g is Theta(N) and f is Theta(N).
