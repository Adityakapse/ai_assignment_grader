public final class AsymQ11 {
    // `mat` is N x N; `b` is sorted ascending of length N.
    public static int f(int[][] mat, int[] b) {
        int n = mat.length;
        int c = 0;
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                if (g(b, mat[i][j]) >= 0) {
                    c++;
                }
            }
        }
        return c;
    }

    private static int g(int[] b, int x) {
        int l = 0;
        int r = b.length - 1;
        while (l <= r) {
            int mid = (l + r) / 2;
            if (b[mid] == x) return mid;
            if (b[mid] < x) l = mid + 1;
            else r = mid - 1;
        }
        return -1;
    }
}

Calculate the asymptotic worst case running time of the functions below, as a function of the side length N of the matrix `mat` (N x N) and the sorted array `b` of length N.

- You must write your answer in the text field provided.
- Your answer should include a detailed analysis of both functions.
- You can use the Theta notation or the big-O notation with tight bounds.
- Your analysis should refer to line numbers.
- For every loop you need to specify the number of iterations and the cost per iteration.
- Each step of the analysis should be justified with one or two sentences.

public final class AsymQ11 {
    // `mat` is N x N; `b` is sorted ascending of length N.
    public static int f(int[][] mat, int[] b) {
        int n = mat.length;
        int c = 0;
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                if (g(b, mat[i][j]) >= 0) {
                    c++;
                }
            }
        }
        return c;
    }

    private static int g(int[] b, int x) {
        int l = 0;
        int r = b.length - 1;
        while (l <= r) {
            int mid = (l + r) / 2;
            if (b[mid] == x) return mid;
            if (b[mid] < x) l = mid + 1;
            else r = mid - 1;
        }
        return -1;
    }
}

SAMPLE SOLUTION:
Let N be the side length of mat and the length of b.

Method f
Part A: the initialisations of n and c - constant time.
Part B (nested loops over i, j): the body runs for every cell of the N x N matrix.
Part C: return c - constant time.

Parts A and C are Theta(1).

Part B (nested loops):
- Iterations: the outer and inner loops each run N times, so the body runs N x N = Theta(N^2) times.
- Cost per iteration: dominated by g(b, mat[i][j]); since g is a binary search over b it costs Theta(log N). The matrix access, comparison and increment are Theta(1). Per iteration: Theta(log N).
- Total cost of Part B: Theta(N^2) x Theta(log N) = Theta(N^2 log N).

Overall running time of f:
Theta(1) + Theta(N^2 log N) + Theta(1) = Theta(N^2 log N).

Method g
Part D: the initialisations of l and r - constant time.
Part E (while loop): standard binary search.
Part F: return -1 - constant time.

Parts D and F are Theta(1).

Part E:
- Iterations: each iteration either returns or halves the interval [l, r], so the loop runs Theta(log N) times.
- Cost per iteration: Theta(1) - one midpoint computation, two array accesses, two comparisons, one update.
- Total cost of Part E: Theta(log N) x Theta(1) = Theta(log N).

Overall running time of g:
Theta(1) + Theta(log N) + Theta(1) = Theta(log N).
