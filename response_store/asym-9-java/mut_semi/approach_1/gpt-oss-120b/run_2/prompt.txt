QUESTION:
Calculate the asymptotic worst case running time of the functions below, as a function of the length N of the input array `a`.

- You must write your answer in the text field provided.
- Your answer should include a detailed analysis of both functions.
- You can use the Theta notation or the big-O notation with tight bounds.
- Your analysis should refer to line numbers.
- For every loop you need to specify the number of iterations and the cost per iteration.
- Each step of the analysis should be justified with one or two sentences.

public final class AsymQ9 {
    // `a` has length N. Your analysis should be based on N.
    public static int f(int[] a) {
        int n = a.length;
        int s = 0;
        int k = n;
        while (k > 0) {
            s += g(a, k);
            k = k / 2;
        }
        return s;
    }

    private static int g(int[] a, int m) {
        int t = 0;
        int j = m;
        while (j > 0) {
            t += a[j - 1];
            j = j / 2;
        }
        return t;
    }
}

SAMPLE SOLUTION:
Let N be the length of array a.

Method f
Part A: the initialisations of n, s and k - constant time.
Part B (while loop): body calls g(a, k) and halves k.
Part C: return s - constant time.

Parts A and C are Theta(1).

Part B (loop):
- Iterations: k starts at N and is halved each iteration, so the loop runs Theta(log N) times.
- Cost per iteration: dominated by g(a, k). In the worst case (the first iteration) m = N, so g costs Theta(log N) (see g below). Per iteration: Theta(log N).
- Total cost of Part B: Theta(log N) iterations x Theta(log N) per iteration = Theta((log N)^2).

Overall running time of f:
Theta(1) + Theta((log N)^2) + Theta(1) = Theta((log N)^2).

Method g
Part D: the initialisations of t and j - constant time.
Part E (while loop): j starts at m and is halved each iteration.
Part F: return t - constant time.

Parts D and F are Theta(1).

Part E:
- Iterations: j starts at m and is replaced by j/2 each iteration, so the loop runs Theta(log m) times; in the worst case m = N, giving Theta(log N) iterations.
- Cost per iteration: Theta(1) - one array read, one += assignment, one division, one comparison.
- Total cost of Part E: Theta(log N) x Theta(1) = Theta(log N).

Overall running time of g (worst case m = N):
Theta(1) + Theta(log N) + Theta(1) = Theta(log N).

STUDENT SOLUTION:
f uses a halving while loop and calls g inside the loop; the outer loop runs about log N times (N is the length of array a). The setup is constant, and each pass costs about as much as g.

Multiplying the log N iterations by the cost of g gives roughly (log N)^2 for f overall.

g uses a halving while loop. It runs Theta(log N) times in the worst case because j is halved each iteration (worst case it starts at N). Each step is constant work - an array read, an addition and a halving, all Theta(1) - so g's loop is Theta(log N) x Theta(1) = Theta(log N).

So overall f is Theta((log N)^2) and g is Theta(log N).
