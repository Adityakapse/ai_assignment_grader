Calculate the asymptotic worst case running time of the functions below, as functions of the length N of array `a` and the length N of the sorted array `b` (both of length N).

- Your answer should include a detailed analysis of both functions.
- You can use the Theta notation or the big-O notation with tight bounds.
- Your analysis should refer to line numbers.
- For every loop you need to specify the number of iterations and the cost per iteration.
- Each step of the analysis should be justified with one or two sentences.

public final class AsymQ19 {
    // `a` has length N; `b` is sorted ascending and also has length N.
    public static int f(int[] a, int[] b) {
        int n = a.length;
        int s = 0;
        for (int i = 0; i < n; i++) {
            for (int j = i; j < n; j++) {
                s += a[j];
            }
        }
        int t = g(b, a[0]);
        return s + t;
    }

    private static int g(int[] b, int x) {
        int l = 0;
        int r = b.length - 1;
        while (l <= r) {
            int mid = (l + r) / 2;
            if (b[mid] == x) return mid;
            if (b[mid] < x) l = mid + 1;
            else r = mid - 1;
        }
        return -1;
    }
}

SAMPLE SOLUTION:
Let N be the length of arrays a and b.

Method f
Part A: the initialisations of n and s - constant time.
Part B (nested loops over i, j): inner loop runs from j = i to N-1.
Part C: t = g(b, a[0]); return s + t - one call to g plus a constant-time return.

Parts A and the return in Part C are Theta(1).

Part B (nested loops):
- Iterations: for each i the inner loop runs N - i times. Total = N + (N-1) + ... + 1 = N(N+1)/2 = Theta(N^2).
- Cost per iteration: Theta(1) - one array read and one += assignment.
- Total cost of Part B: Theta(N^2) x Theta(1) = Theta(N^2).

Part C:
- The call g(b, a[0]) is a binary search costing Theta(log N) (see g below); the addition and return are Theta(1).
- Total cost of Part C: Theta(log N).

Overall running time of f:
Theta(1) + Theta(N^2) (Part B) + Theta(log N) (Part C) = Theta(N^2), absorbing the lower-order Theta(log N) term.

Method g
Part D: the initialisations of l and r - constant time.
Part E (while loop): standard binary search.
Part F: return -1 - constant time.

Parts D and F are Theta(1).

Part E:
- Iterations: each iteration either returns or halves the interval [l, r], so the loop runs Theta(log N) times.
- Cost per iteration: Theta(1) - one midpoint computation, two array accesses, two comparisons, one update.
- Total cost of Part E: Theta(log N) x Theta(1) = Theta(log N).

Overall running time of g:
Theta(1) + Theta(log N) + Theta(1) = Theta(log N).

STUDENT SOLUTION:
f has two nested loops over a where the inner starts at i, so it runs in O(N). Inside the loop it only does an array read and an addition, which are simple constant operations. The g function does a binary search on b with simple constant operations inside, and seems logarithmic. So the answer is f = O(N) and g = O(N).
