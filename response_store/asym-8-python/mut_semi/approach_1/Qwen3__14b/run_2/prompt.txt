QUESTION:
Calculate the asymptotic worst case running time of the functions below, as functions of the length N of array `a` and the length N of the sorted array `b` (both of length N).

- You must write your answer in the text field provided.
- Your answer should include a detailed analysis of both functions.
- You can use the Theta notation or the big-O notation with tight bounds.
- Your analysis should refer to line numbers.
- For every loop you need to specify the number of iterations and the cost per iteration.
- Each step of the analysis should be justified with one or two sentences.

def f(a, b):
    n = len(a)
    c = 0
    for i in range(n):
        if g(b, a[i]) >= 0:
            c += 1
    return c

def g(b, x):
    l = 0
    r = len(b) - 1
    while l <= r:
        mid = (l + r) // 2
        if b[mid] == x:
            return mid
        if b[mid] < x:
            l = mid + 1
        else:
            r = mid - 1
    return -1

SAMPLE SOLUTION:
Let N be the length of arrays a and b.

Method f
Part A: the initialisations of n and c - constant time.
Part B (for loop): runs over i = 0..N-1.
Part C: return c - constant time.

Parts A and C are Theta(1).

Part B (loop):
- Iterations: i runs from 0 to N-1, so Theta(N) iterations.
- Cost per iteration: dominated by g(b, a[i]); since g is a binary search over b it costs Theta(log N). The comparison and increment are Theta(1). Per iteration: Theta(log N).
- Total cost of Part B: Theta(N) x Theta(log N) = Theta(N log N).

Overall running time of f:
Theta(1) + Theta(N log N) + Theta(1) = Theta(N log N).

Method g
Part D: the initialisations of l and r - constant time.
Part E (while loop): standard binary search.
Part F: return -1 - constant time.

Parts D and F are Theta(1).

Part E:
- Iterations: each iteration either returns or halves the interval [l, r], so the loop runs Theta(log N) times.
- Cost per iteration: Theta(1) - one midpoint computation, two array accesses, two comparisons, one update.
- Total cost of Part E: Theta(log N) x Theta(1) = Theta(log N).

Overall running time of g:
Theta(1) + Theta(log N) + Theta(1) = Theta(log N).

STUDENT SOLUTION:
f uses a for loop over a and calls g inside the loop; the outer loop runs about N times (N is the length of a and b). The setup is constant, and each pass costs about as much as g.

Multiplying the N iterations by the cost of g gives roughly N log N for f overall.

g uses a binary search while loop. It runs Theta(log N) times in the worst case because the search interval halves each iteration. Each step is constant work - a midpoint, two array accesses and a comparison, all Theta(1) - so g's loop is Theta(log N) x Theta(1) = Theta(log N).

So overall f is Theta(N log N) and g is Theta(log N).
