QUESTION:
Calculate the asymptotic worst case running time of the functions below, as a function of the length N of the input array `a`.

- You must write your answer in the text field provided.
- Your answer should include a detailed analysis of both functions.
- You can use the Theta notation or the big-O notation with tight bounds.
- Your analysis should refer to line numbers.
- For every loop you need to specify the number of iterations and the cost per iteration.
- Each step of the analysis should be justified with one or two sentences.

def f(a):
    n = len(a)
    s = 0
    for i in range(n):
        s += a[i]
    t = g(a)
    return s + t

def g(a):
    n = len(a)
    t = 0
    k = n
    while k > 0:
        t += a[k - 1]
        k = k // 2
    return t

SAMPLE SOLUTION:
Let N be the length of array a.

Method f
Part A: the initialisations of n and s - constant time.
Part B (single for loop over i): sums the array.
Part C: t = g(a); return s + t - one call to g plus a constant-time return.

Parts A and the return in Part C are Theta(1).

Part B (loop):
- Iterations: i runs from 0 to N-1, so Theta(N) iterations.
- Cost per iteration: Theta(1) - one array read and one += assignment.
- Total cost of Part B: Theta(N) x Theta(1) = Theta(N).

Part C:
- The call g(a) costs Theta(log N) (see g below); the addition and return are Theta(1).
- Total cost of Part C: Theta(log N).

Overall running time of f:
Theta(1) + Theta(N) + Theta(log N) = Theta(N), because log N is dominated by N.

Method g
Part D: the initialisations of n, t and k - constant time.
Part E (while loop): each iteration reads a[k-1] and halves k.
Part F: return t - constant time.

Parts D and F are Theta(1).

Part E:
- Iterations: k starts at N and is replaced by k/2 each iteration, so the loop runs Theta(log N) times until k becomes 0.
- Cost per iteration: Theta(1) - one array read, one += assignment, one integer division, one comparison.
- Total cost of Part E: Theta(log N) x Theta(1) = Theta(log N).

Overall running time of g:
Theta(1) + Theta(log N) + Theta(1) = Theta(log N).

STUDENT SOLUTION:
f has a single for loop over a and then calls g. The setup statements are constant.

The loop in f runs about N iterations in total (N is the length of array a). Each pass does an array read and an addition, all Theta(1) simple operations, so f's own loop work is Theta(N).

The call to g afterwards adds some more cost on top.

g uses a while loop that runs Theta(log N) times. Every iteration does an array read, an addition and a halving of k, all Theta(1), so the loop is Theta(log N) x Theta(1) = Theta(log N).

Putting it together, g is Theta(log N) and f is Theta(N).
