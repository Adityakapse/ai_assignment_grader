def f(a):
    n = len(a)
    s = 0
    for i in range(n):
        for j in range(i + 1):
            s += a[j] * a[i]
    t = g(a)
    return s + t

def g(a):
    n = len(a)
    t = 0
    k = n
    while k > 0:
        t += a[k - 1]
        k = k // 2
    return t

Let N be the length of array a.

Method f
Part A: n = len(a); s = 0 - constant-time initialisation.
Part B (nested loops over i, j): the body runs for every (i, j) with 0 <= j <= i < N.
Part C: t = g(a); return s + t - one call to g plus a constant-time return.

Parts A and the return in Part C are Theta(1).

Part B (nested loops):
- Iterations: i = 0 gives 1 inner step, i = 1 gives 2, ..., i = N-1 gives N. Total = 1 + 2 + ... + N = N(N+1)/2 = Theta(N^2).
- Cost per iteration: Theta(1) - two array reads, one multiplication, one += assignment.
- Total cost of Part B: Theta(N^2) x Theta(1) = Theta(N^2).

- Total cost of Part C: Theta(log N).

Theta(1) + Theta(N^2) + Theta(log N) = Theta(N^2).

Method g
Part D: n = len(a); t = 0; k = n - constant time.
Part E (while loop): each iteration reads a[k-1] and halves k.
Part F: return t - constant time.

Parts D and F are Theta(1).

Part E:
- Iterations: k starts at N and becomes k // 2 each iteration, so the loop runs Theta(log N) times until k is 0.
- Cost per iteration: Theta(1) - one array read, one += assignment, one integer division, one comparison.
- Total cost of Part E: Theta(log N) x Theta(1) = Theta(log N).

Overall running time of g:
Theta(1) + Theta(log N) + Theta(1) = Theta(log N).
