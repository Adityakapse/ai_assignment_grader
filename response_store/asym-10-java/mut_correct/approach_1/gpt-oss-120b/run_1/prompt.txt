Calculate the asymptotic worst case running time of the functions below, as a function of the length N of the input array `a`.

- You must write your answer in the text field provided.
- Your answer should include a detailed analysis of both functions.
- You can use the Theta notation or the big-O notation with tight bounds.
- Your analysis should refer to line numbers.
- For every loop you need to specify the number of iterations and the cost per iteration.
- Each step of the analysis should be justified with one or two sentences.

public final class AsymQ10 {
    // `a` has length N. Your analysis should be based on N.
    public static int f(int[] a) {
        int n = a.length;
        int s = 0;
        for (int i = 0; i < n; i++) {
            s += a[i] * 2;
        }
        int t = g(a);
        return s + t;
    }

    private static int g(int[] a) {
        int n = a.length;
        int t = 0;
        for (int i = 0; i < n; i++) {
            t += a[i];
        }
        return t;
    }
}

Parts A and the return in Part C are Theta(1).

- Cost per iteration: Theta(1) - one array read, one multiplication, one += assignment.
- Total cost of Part B: Theta(N) x Theta(1) = Theta(N).

Part C:
- The call g(a) is a second linear pass costing Theta(N) (see g below); the addition and return are Theta(1).
- Total cost of Part C: Theta(N).

Theta(1) + Theta(N) (Part B) + Theta(N) (Part C) = Theta(N). The two passes run one after another, so their costs ADD (Theta(N) + Theta(N) = Theta(N)); they are not multiplied.
