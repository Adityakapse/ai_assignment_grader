QUESTION:
Calculate the asymptotic worst case running time of the functions below, as a function of the side length N of the input matrix `mat` (which is N x N).

- You must write your answer in the text field provided.
- Your answer should include a detailed analysis of both functions.
- You can use the Theta notation or the big-O notation with tight bounds.
- Your analysis should refer to line numbers.
- For every loop you need to specify the number of iterations and the cost per iteration.
- Each step of the analysis should be justified with one or two sentences.

def f(mat):
    n = len(mat)
    s = 0
    for i in range(n):
        s += mat[i][0]
    t = g(mat)
    return s + t

def g(mat):
    n = len(mat)
    t = 0
    for i in range(n):
        for j in range(n):
            t += mat[i][j]
    return t

SAMPLE SOLUTION:
Let N be the side length of the matrix mat (mat is N x N).

Method f
Part A: the initialisations of n and s - constant time.
Part B (for loop): a single loop reading the first column of mat.
Part C: t = g(mat); return s + t - one call to g plus a constant-time return.

Parts A and the return in Part C are Theta(1).

Part B (loop):
- Iterations: i runs from 0 to N-1, so Theta(N) iterations.
- Cost per iteration: Theta(1) - one matrix access and one += assignment.
- Total cost of Part B: Theta(N) x Theta(1) = Theta(N).

Part C:
- The call g(mat) costs Theta(N^2) (see g below); the addition and return are Theta(1).
- Total cost of Part C: Theta(N^2).

Overall running time of f:
Theta(1) + Theta(N) (Part B) + Theta(N^2) (Part C) = Theta(N^2). Here the helper g dominates f's own loop, so the lower-order Theta(N) term is absorbed.

Method g
Part D: the initialisations of n and t - constant time.
Part E (nested loops over i, j): visits every cell of the N x N matrix.
Part F: return t - constant time.

Parts D and F are Theta(1).

Part E:
- Iterations: the outer and inner loops each run N times, so the body runs N x N = Theta(N^2) times.
- Cost per iteration: Theta(1) - one matrix access and one += assignment.
- Total cost of Part E: Theta(N^2) x Theta(1) = Theta(N^2).

Overall running time of g:
Theta(1) + Theta(N^2) + Theta(1) = Theta(N^2).

STUDENT SOLUTION:
f has a single loop over the first column of mat, so it runs in O(N). Inside the loop it only does a matrix access and an addition, which are simple constant operations. The g function scans the whole matrix with simple constant operations inside, and seems quadratic. So the answer is f = O(N) and g = O(N).
