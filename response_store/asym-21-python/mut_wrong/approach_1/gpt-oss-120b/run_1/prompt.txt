QUESTION:
Calculate the asymptotic worst case running time of the functions below, as a function of the number of nodes N in the linked list with head h.

- You must write your answer in the text field provided.
- Your answer should include a detailed analysis of both functions.
- You can use the Theta notation or the big-O notation with tight bounds.
- Your analysis should refer to line numbers.
- For every loop you need to specify the number of iterations and the cost per iteration.
- Each step of the analysis should be justified with one or two sentences.

class Node:
    def __init__(self, v, nxt):
        self.v = v
        self.next = nxt

h = None  # head of the linked list

def f():
    s = 0
    p = h
    while p is not None:
        s += g()
        p = p.next
    return s

def g():
    c = 0
    q = h
    while q is not None:
        c += q.v
        q = q.next
    return c

SAMPLE SOLUTION:
Let N be the number of nodes in the linked list with head h.

Method f
Part A: the initialisations of s and p - constant time.
Part B (while loop): traverses the list from h, calling g() at each node.
Part C: return s - constant time.

Parts A and C are Theta(1).

Part B (loop):
- Iterations: p advances by p.next each iteration, so starting from h the loop runs exactly N times before p becomes null. Theta(N) iterations.
- Cost per iteration: dominated by g(), which scans the WHOLE list from the head every time and costs Theta(N) (see g below). The pointer advance is Theta(1). Per iteration: Theta(N).
- Total cost of Part B: Theta(N) iterations x Theta(N) per iteration = Theta(N^2).

Overall running time of f:
Theta(1) + Theta(N^2) + Theta(1) = Theta(N^2).

Method g
Part D: the initialisations of c and q - constant time.
Part E (while loop): traverses the entire list from the head h.
Part F: return c - constant time.

Parts D and F are Theta(1).

Part E:
- Iterations: q starts at h and advances by q.next until null, visiting all N nodes; Theta(N) iterations.
- Cost per iteration: Theta(1) - one field access, one += assignment, one pointer advance, one null comparison.
- Total cost of Part E: Theta(N) x Theta(1) = Theta(N).

Overall running time of g:
Theta(1) + Theta(N) + Theta(1) = Theta(N).

STUDENT SOLUTION:
f walks the list, so it is O(N). It calls g inside, but the operations are simple and constant. g also walks the whole list doing simple constant work, so it looks linear. The answer is f = O(N) and g = O(1).
