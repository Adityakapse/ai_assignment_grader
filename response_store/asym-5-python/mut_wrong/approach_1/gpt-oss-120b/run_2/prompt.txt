QUESTION:
Calculate the asymptotic worst case running time of the functions below, as a function of the number of nodes N in the linked list with head h.

- You must write your answer in the text field provided.
- Your answer should include a detailed analysis of both functions.
- You can use the Theta notation or the big-O notation with tight bounds.
- Your analysis should refer to line numbers.
- For every loop you need to specify the number of iterations and the cost per iteration.
- Each step of the analysis should be justified with one or two sentences.

class Node:
    def __init__(self, v, nxt):
        self.v = v
        self.next = nxt

h = None  # head of the linked list

def f():
    s = 0
    p = h
    while p is not None:
        s += g(p)
        p = p.next
    return s

def g(start):
    c = 0
    q = start
    while q is not None:
        c += q.v
        q = q.next
    return c

SAMPLE SOLUTION:
Let N be the number of nodes in the linked list with head h.

Method f
Part A: s = 0; p = h - constant time.
Part B (while loop): traverses the list, calling g(p) at each node.
Part C: return s - constant time.

Parts A and C are Theta(1).

Part B (loop):
- Iterations: p advances by p.next each iteration, so starting from h the loop runs exactly N times before p becomes None. Theta(N) iterations.
- Cost per iteration: dominated by g(p). In the worst case g scans from p to the end of the list - when p = h this is N nodes. The per-iteration cost is therefore Theta(N) in the worst case.
- Total cost of Part B: summing the actual per-iteration costs gives N + (N-1) + ... + 1 = N(N+1)/2 = Theta(N^2). Equivalently, Theta(N) iterations x Theta(N) worst-case per iteration = Theta(N^2).

Overall running time of f:
Theta(1) + Theta(N^2) + Theta(1) = Theta(N^2).

Method g
Part D: c = 0; q = start - constant time.
Part E (while loop): traverses from start to the end of the list.
Part F: return c - constant time.

Parts D and F are Theta(1).

Part E:
- Iterations: q advances by q.next until None. In the worst case start = h, so the loop visits all N nodes; the iteration count is Theta(N).
- Cost per iteration: Theta(1) - one += assignment, one pointer advance, one None comparison.
- Total cost of Part E: Theta(N) x Theta(1) = Theta(N).

Overall running time of g:
Theta(1) + Theta(N) + Theta(1) = Theta(N).

STUDENT SOLUTION:
f walks through nodes of the linked list which takes linear time. g also walks the list and counts something. Both functions are O(N). The answer is f = O(N) and g = O(N).
