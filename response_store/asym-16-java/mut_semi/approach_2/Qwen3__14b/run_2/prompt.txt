Calculate the asymptotic worst case running time of the functions below, as a function of the length N of the input array `a`.

- You must write your answer in the text field provided.
- Your answer should include a detailed analysis of both functions.
- You can use the Theta notation or the big-O notation with tight bounds.
- Your analysis should refer to line numbers.
- For every loop you need to specify the number of iterations and the cost per iteration.
- Each step of the analysis should be justified with one or two sentences.

public final class AsymQ16 {
    // `a` has length N. Your analysis should be based on N.
    public static int f(int[] a) {
        int n = a.length;
        int s = 0;
        for (int k = 1; k <= n; k = k * 2) {
            for (int j = 0; j < n; j++) {
                s += a[j];
            }
        }
        int t = g(a);
        return s + t;
    }

    private static int g(int[] a) {
        int n = a.length;
        int t = 0;
        for (int i = 0; i < n; i++) {
            t += a[i];
        }
        return t;
    }
}

SAMPLE SOLUTION:
Let N be the length of array a.

Method f
Part A: the initialisations of n, s and k - constant time.
Part B (nested loops): the outer variable k takes the values 1, 2, 4, ..., up to N; the inner loop runs the full N each time.
Part C: t = g(a); return s + t - one call to g plus a constant-time return.

Parts A and the return in Part C are Theta(1).

Part B (nested loops):
- Iterations: the outer loop runs Theta(log N) times (k doubles until it exceeds N); the inner loop runs exactly N times each, independent of k. Total = Theta(log N) x Theta(N) = Theta(N log N).
- Cost per iteration: Theta(1) - one array read and one += assignment.
- Total cost of Part B: Theta(N log N).

Part C:
- The call g(a) costs Theta(N) (see g below); the addition and return are Theta(1).
- Total cost of Part C: Theta(N).

Overall running time of f:
Theta(1) + Theta(N log N) + Theta(N) = Theta(N log N), absorbing the lower-order Theta(N) term.

Method g
Part D: the initialisations of n and t - constant time.
Part E (for loop): one linear pass over a.
Part F: return t - constant time.

Parts D and F are Theta(1).

Part E:
- Iterations: i runs from 0 to N-1, giving Theta(N) iterations.
- Cost per iteration: Theta(1) - one array read and one += assignment.
- Total cost of Part E: Theta(N) x Theta(1) = Theta(N).

Overall running time of g:
Theta(1) + Theta(N) + Theta(1) = Theta(N).

STUDENT SOLUTION:
f has a doubling outer loop with a full inner pass over a and then calls g. The setup statements are constant.

The loop in f runs about N log N iterations in total (N is the length of array a). Each pass does an array read and an addition, all Theta(1) simple operations, so f's own loop work is Theta(N log N).

The call to g afterwards adds some more cost on top.

g uses a single for loop that runs Theta(N) times. Every iteration does an array read and an addition, all Theta(1), so the loop is Theta(N) x Theta(1) = Theta(N).

Putting it together, g is Theta(N) and f is Theta(N log N).
