public final class AsymQ21 {
    static class Node {
        int v;
        Node next;
        Node(int v, Node next) { this.v = v; this.next = next; }
    }

    static Node h;   // head of the linked list

    // Your analysis should be based on the number of nodes N in the list with head h.
    public static int f() {
        int s = 0;
        Node p = h;
        while (p != null) {
            s += g();
            p = p.next;
        }
        return s;
    }

    private static int g() {
        int c = 0;
        Node q = h;
        while (q != null) {
            c += q.v;
            q = q.next;
        }
        return c;
    }
}

Method f
Part A: the initialisations of s and p - constant time.
Part B (while loop): traverses the list from h, calling g() at each node.
Part C: return s - constant time.

Parts A and C are Theta(1).

- Iterations: p advances by p.next each iteration, so starting from h the loop runs exactly N times before p becomes null. Theta(N) iterations.
- Cost per iteration: dominated by g(), which scans the WHOLE list from the head every time and costs Theta(N) (see g below). The pointer advance is Theta(1). Per iteration: Theta(N).
- Total cost of Part B: Theta(N) iterations x Theta(N) per iteration = Theta(N^2).

Overall running time of f:
Theta(1) + Theta(N^2) + Theta(1) = Theta(N^2).

Method g
Part D: the initialisations of c and q - constant time.
Part E (while loop): traverses the entire list from the head h.
Part F: return c - constant time.

Parts D and F are Theta(1).

Part E:
- Iterations: q starts at h and advances by q.next until null, visiting all N nodes; Theta(N) iterations.
- Cost per iteration: Theta(1) - one field access, one += assignment, one pointer advance, one null comparison.
- Total cost of Part E: Theta(N) x Theta(1) = Theta(N).
