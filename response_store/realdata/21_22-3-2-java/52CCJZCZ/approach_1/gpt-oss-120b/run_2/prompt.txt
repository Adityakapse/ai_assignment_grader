QUESTION:
The goal of this task is to find the longest path in the dag (directed acyclic
graph) in $O(N+M)$. 

Input: A natural number $1 \leq N \leq 2500$, which indicates how many
nodes the graph $G$ has. A two dimensional array $A$ of the
size $1 \leq M \leq 10^6$ of integers
$A = [[a^{1}_1,a^{2}_1],[a^{1}_2,a^{2}_2],...,[a^{1}_M,a^{2}_M]]$, which
encodes the node and edge set of $G$.  If $[a,b] \in A$, then
there is a directed edge from the node$a$ to the node $b$. You
may assume that there are no directed cycles in $G$. An
example: let $N = 3$ and the edges $A = [[1,2],[2,3]]$ then the result is
the following graph:

[]

Output: The length of the longest directed path in $G$.
Your algorithm must compute the solution in $O(N+M)$.

Time limit: 1 CPU second ($O(N+M)$ ).

SAMPLE SOLUTION:
int dfs(int node,ArrayList<ArrayList<Integer>> graph,int[] memo){
    if(graph.get(node).size() == 0){
        return 0;
    }
    else if(memo[node] != -1)
        return memo[node];
    else
    {
        int sol = 0;
        for (int i = 0; i < graph.get(node).size(); i++) {
            sol = Math.max(sol,dfs(graph.get(node).get(i),graph,memo) + 1);
        }
        memo[node] = sol;
        return memo[node];
    }
}

int calc(int N, int[][] A){
    ArrayList<ArrayList<Integer>> graph = new ArrayList<>(N+1);
    for (int i = 0; i <= N; i++) {
      graph.add(new ArrayList<>());
      if(i != 0)
          graph.get(0).add(i); 
    }
    for (int i = 0; i < A.length; i++) {
      int start,end;
      start = A[i][0];
      end = A[i][1];
      graph.get(start).add(end);
    }
    int[] memo = new int[N+1];
    for (int i = 0; i <= N; i++) {
      memo[i] = -1;
    }
    return dfs(0,graph,memo)-1;
}

STUDENT SOLUTION:
int calc(int N, int[][] A){
    
    // Erstellen der Adjazenzliste des Graphen
    ArrayList<ArrayList<Integer>> adj 
        = new ArrayList<ArrayList<Integer>>(N);
    for(int i=0; i<N; i++) {
        adj.add(i,new ArrayList<Integer>(N));
    }
    for(int i=0; i<A.length; i++) {
        adj.get(A[i][0]-1).add(A[i][1]-1);
    }
    
    // Erstellt topologisch sortierten Array der Knoten
    int[] topoList = topoSort(adj);
    
    // in[x] speichert den längsten Pfad, der im
    // Knoten x endet
    int[] in = new int[N];
    
    // Geht alle Knoten in der topologischen Reihenfolge 
    // durch und aktualisiert den in-Wert von allen Knoten
    // die in dessen Adjazenzliste sind
    for(int j=0; j<N; j++) {
        int a = topoList[j];
        ArrayList<Integer> it = adj.get(a);
        for(int k=0; k<it.size();k++) {
            int i = it.get(k);
            if(in[a]+1>in[i]) {
                in[i] = in[a]+1;
            }
        }
    }
    
    // Sucht den größten Wert aus dem Array "in"
    int maxPfad = 0;
    for(int i=0;i<N;i++) {
        if(in[i]>maxPfad){
            maxPfad=in[i];
        }
    }
    
    return maxPfad;
}

// Hilfsmethode von topoSort
// Zuerst wird
void topoSortUtil(int v, boolean visited[],
        ArrayList<Integer> list, 
        ArrayList<ArrayList<Integer>> adj) {
    visited[v] = true;
    Integer i;
    ArrayList<Integer> it = adj.get(v);
    for(int j=0; j<it.size();j++) {
        i = it.get(j);
        if(!visited[i]) {
            topoSortUtil(i,visited,list,adj);
        }
    }
    list.add(new Integer(v));
}

// Erstellt aus der Adjazenzliste adj einen
// topologisch sortierten Array der Knoten
int[] topoSort(ArrayList<ArrayList<Integer>> adj) {
    int n = adj.size();
    ArrayList<Integer> list = new ArrayList<Integer>(n);
    boolean visited[] = new boolean[n];
    for (int i = 0; i < n; i++) {
        if (!visited[i]) {
            topoSortUtil(i, visited, list, adj);
        }
    }
    
    int[] topoList = new int[n];
    for(int i=0; i<n;i++) {
        topoList[i] = list.get(n-i-1);
    }
    return topoList;
}

RUBRIC:
Point 1 — Graph construction and virtual source (valid range: 0–20)
  An adjacency list is built from A, and a virtual source node 0 is added with edges to all nodes 1 to N so that a single DFS covers all nodes.

Point 2 — Memoization: initialisation and cache check (valid range: 0–20)
  A memo array is initialised to -1 for all nodes, and if memo[node] != -1 the cached value is returned immediately without recomputation.

Point 3 — DFS base case: leaf node (valid range: 0–15)
  When a node has no outgoing edges (leaf), the function returns 0.

Point 4 — Recurrence: longest path over children (valid range: 0–20)
  For each child of node, sol = max(sol, dfs(child) + 1) is computed; the result is stored in memo[node] before returning.

Point 5 — Overall correctness (valid range: 0–25)
  calc returns the correct length of the longest directed path in the DAG for all valid inputs.
