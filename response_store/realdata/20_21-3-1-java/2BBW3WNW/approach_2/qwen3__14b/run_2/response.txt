### ✅ **Key Features of the Code**

- **Dynamic Programming Table (`dynTab`)**
  - The table is defined as `dynTab[i][j]`, where:
    - `i` is the index of the item being considered (from 0 to `nItem`).
    - `j` is the current capacity (from 0 to `capacity`).
  - `dynTab[i][j]` stores the **maximum value** that can be achieved by considering the first `i` items with a capacity of `j`.

- **Initialization**
  - The first row of the table (`dynTab[0][j]`) is initialized to `0` for all values of `j`, since no items are selected.

- **Transition Logic**
  - For each item `i` and each capacity `j`:
    - If the current item's weight is **greater than `j`**, the item cannot be selected, so the value is inherited from the previous row (`dynTab[i-1][j]`).
    - If the item's weight is **less than or equal to `j`**, the algorithm considers both options:
      - Not taking the item: `dynTab[i-1][j]`
      - Taking the item: `dynTab[i-1][j - weight] + value`
    - The maximum of these two options is stored in `dynTab[i][j]`.

- **Handling Items with Zero Weight**
  - Even if an item has a weight of zero, the algorithm ensures that the item is only selected **once**. The logic still adheres to the 0/1 knapsack rule, as the item is processed only once in the iteration.
