### **Code Analysis:**
```python
def rob(nums):
    a, b = 0, 0
    for num in nums:
        if num % 2 == 0:
            a = max(a + num, b)
        else:
            b = max(b + num, a)
    return max(a, b)
```

  - If the index is odd, we update `b` similarly.
