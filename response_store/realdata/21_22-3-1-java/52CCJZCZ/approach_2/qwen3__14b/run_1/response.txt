### 🔍 **Understanding the Problem**

We are given a list of numbers, and we want to select a subset of these numbers such that:

- No two selected elements are adjacent.
- The sum of the selected elements is maximized.

For example, given the input `[1, 2, 3, 4, 5]`, the optimal selection is `[2, 4]` with a sum of `6`.

---

### 📌 **Standard Dynamic Programming Approach**

The standard solution uses a dynamic programming array `dp`, where `dp[i]` represents the maximum sum we can get from the first `i` elements:

- `dp[0] = nums[0]`
- `dp[1] = max(nums[0], nums[1])`
- For `i >= 2`, `dp[i] = max(dp[i-1], dp[i-2] + nums[i])`

This is an O(n) time and O(n) space solution.

---

### 🧠 **Code's Approach: Efficient Space Optimization**

The provided code uses **two variables `a` and `b`**, which effectively simulate the `dp[i-2]` and `dp[i-1]` values from the standard approach, but with **constant space**.

Here's how it works:

- Initialize `a = 0`, `b = 0`.
- For each index `i` in the list:
  - If `i` is **even**, compute `a = max(a + nums[i], b)`.
  - If `i` is **odd**, compute `b = max(b + nums[i], a)`.

This approach is **equivalent** to the standard DP solution, but it uses **only two variables** instead of a full array. It cleverly alternates between `a` and `b` to simulate the recurrence relation.

---

### ✅ **Why This Works**

The logic behind the code is based on the observation that:

- At each step, you have two options:
  1. **Take** the current element, and add it to the best sum from **two steps back**.
  2. **Don't take** the current element, and use the best sum from **one step back**.

By alternating between `a` and `b` based on the parity of the index, the code correctly captures this behavior.
