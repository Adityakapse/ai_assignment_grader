### ✅ **Key Points of the Code**

1. **Function Signature**:
   ```python
   def knapsack(values, weights, capacity):
   ```
   The function takes a list of item values (`values`), a list of item weights (`weights`), and a `capacity` (maximum weight the knapsack can hold).

2. **Memoization Table**:
   ```python
   memo = [[-1 for _ in range(capacity + 1)] for _ in range(len(values) + 1)]
   ```
   A 2D list `memo` is used to store computed values for subproblems. `memo[i][j]` represents the maximum value achievable using the first `i` items and a capacity of `j`.

3. **Recursive Helper Function**:
   ```python
   def helper(amount, cap):
       if memo[amount][cap] != -1:
           return memo[amount][cap]
       if amount == 0 or cap == 0:
           return 0
       # Option 1: Skip the current item
       skip = helper(amount - 1, cap)
       # Option 2: Take the current item if possible
       take = 0
       if weights[amount - 1] <= cap:
           take = values[amount - 1] + helper(amount - 1, cap - weights[amount - 1])
       memo[amount][cap] = max(skip, take)
       return memo[amount][cap]
   ```
   - This function uses recursion with memoization to compute the optimal solution.
   - At each step, it considers two options: skipping the current item or taking it (if the weight allows).
   - The result is stored in `memo[amount][cap]`.

4. **Base Case**:
   ```python
   if amount == 0 or cap == 0:
       return 0
   ```
   If there are no items or no capacity left, the maximum value is 0.

5. **Return Value**:

   The final result is obtained by calling the helper function with all items and full capacity.
