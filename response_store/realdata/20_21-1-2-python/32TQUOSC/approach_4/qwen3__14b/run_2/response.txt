### ✅ **Code Overview**

```python
def solution(A):
    if len(A) <= 1:
        return A
    mid = len(A) // 2
    A1 = A[:mid]
    A2 = A[mid:]
    A1 = solution(A1)
    A2 = solution(A2)
    A = A1 + A2
    merge(A, mid, len(A))
    return A
```

```python
def merge(A, p, r):
    n1 = p
    n2 = r - p
    L = []
    R = []
    for i in range(n1):
        L.append(A[i])
    for i in range(n2):
        R.append(A[p + i])
    L.append(float('inf'))
    R.append(float('inf'))
    i = j = k = 0
    while k < r:
        if L[i] <= R[j]:
            A[k] = L[i]
            i += 1
        else:
            A[k] = R[j]
            j += 1
        k += 1
```

---

### 🧠 **Explanation of the Algorithm**

#### **1. Base Case**
- If the length of the array `A` is 0 or 1, it is already sorted. The function returns `A` immediately.

#### **2. Divide Step**
- The array is split into two halves: `A1` (first half) and `A2` (second half).
- Each half is recursively sorted using the `solution` function.

#### **3. Conquer Step**
- The sorted halves `A1` and `A2` are concatenated into a new array `A = A1 + A2`.
- The `merge` function is called to merge the two sorted halves into a single sorted array.

#### **4. Merge Function**
- The `merge` function takes the array `A`, the length of the first half (`p`), and the total length of the array (`r`).
- It creates two temporary arrays `L` and `R` from the first and second halves respectively.
- Sentinel values (`float('inf')`) are added to the end of both `L` and `R` to simplify the merge loop.
- The arrays `L` and `R` are merged back into `A` by comparing elements from each and placing the smaller one at the current position in `A`.
