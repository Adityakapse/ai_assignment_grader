```python
def merge_sort(arr):
    if len(arr) <= 1:
        return arr
    mid = len(arr) // 2
    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])
    return merge(left, right)

def merge(left, right):
    result = []
    i = j = 0
    while i < len(left) and j < len(right):
        if left[i] < right[j]:
            result.append(left[i])
            i += 1
        else:
            result.append(right[j])
            j += 1
    result.extend(left[i:])
    result.extend(right[j:])
    return result
```

This is a **standard implementation of Merge Sort**:

1. **Base Case**: If the array has 0 or 1 element, it is already sorted and returned immediately.
2. **Divide**: The array is split into two halves, `left` and `right`.
3. **Conquer**: Each half is recursively sorted.
4. **Merge**: The sorted halves are merged into a single sorted array.
