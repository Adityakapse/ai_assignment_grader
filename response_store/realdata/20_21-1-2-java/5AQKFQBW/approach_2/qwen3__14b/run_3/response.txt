### **Overview of Merge Sort**
Merge Sort is a **divide-and-conquer** algorithm that:
1. **Divides** an array into two halves.
2. **Recursively sorts** each half.
3. **Merges** the sorted halves back into a single sorted array.

---

### **Key Components in the Code**

#### **1. `mergeSort` Function**
```java
private static int[] mergeSort(int[] arr, int n) {
    if (n <= 1) return arr; // Base case: array of size 0 or 1 is already sorted

    int mid = n / 2;
    int[] left = Arrays.copyOfRange(arr, 0, mid);
    int[] right = Arrays.copyOfRange(arr, mid, n);

    mergeSort(left, mid);   // Recursively sort the left half
    mergeSort(right, n - mid); // Recursively sort the right half

    return merge(arr, left, right, mid, n - mid);
}
```
- **Splitting the Array**: The array is split into `left` and `right` subarrays using `Arrays.copyOfRange`.
- **Recursive Sorting**: Each subarray is sorted recursively.
- **Merging**: The sorted subarrays are merged into the original array `arr`.

---

#### **2. `merge` Function**
```java
private static int[] merge(int[] arr, int[] left, int[] right, int lSize, int rSize) {
    int i = 0, j = 0, k = 0;

    while (i < lSize && j < rSize) {
        if (left[i] <= right[j]) {
            arr[k++] = left[i++]; // Place smaller element in `arr`
        } else {
            arr[k++] = right[j++];
        }
    }

    while (i < lSize) {
        arr[k++] = left[i++];
    }

    while (j < rSize) {
        arr[k++] = right[j++];
    }

    return arr;
}
```
- **Merging Logic**: The `merge` function merges the sorted `left` and `right` arrays into the original `arr`.
- **In-place Modification**: The original array `arr` is modified directly during the merge process.

   - The recursive calls to `mergeSort` on the `left` and `right` arrays ensure that the entire array is eventually broken down into base cases (arrays of size 0 or 1), which are trivially sorted.

3. **Correct Merging**:
