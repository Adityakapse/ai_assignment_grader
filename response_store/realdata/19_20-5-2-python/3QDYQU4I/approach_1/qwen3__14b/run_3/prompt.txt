QUESTION:
As a second algorithm - analogous to the first task - a depth
depth-first search is to be implemented.

Here, too, the nodes are to be visited in the order in which they appear in the adjacency list.

SAMPLE SOLUTION:
def dfs(graph, start):
    visited, queue = list(), [start]
    while queue:
        next = queue.pop()
        if next not in visited:
            visited.append(next)
            for vertex in reversed(graph[next]): # Need to reverse list in order to visit vertex in correct order
                if vertex not in visited:
                    queue.append(vertex)
    return visited

STUDENT SOLUTION:
def dfs_help(graph, stack, visited):
    
    # if we have no nodes left to visit, return the result
    if len(stack) == 0:
        return visited
    
    # otherwise the stack has nodes left. 
    # add the top-most of these to the visited nodes and stack 
    # its neighbours that are not already visited. If they are
    # already stacked, move them to the top
    node = stack.pop()
    visited.append(node)
    for neighbour in reversed(graph[node]):
        if neighbour not in visited:
            if neighbour not in stack:
                stack.append(neighbour)
            else:
                stack.remove(neighbour)
                stack.append(neighbour)
        
    return dfs_help(graph, stack, visited)

def dfs(graph, start):
    return dfs_help(graph, [start], [])

RUBRIC:
Point 1 — DFS loop structure and initialisation (valid range: 0–20)
  The start node is pushed onto the stack before the loop, and a while loop processes nodes until the stack is empty.

Point 2 — LIFO pop: removing from the top (valid range: 0–20)
  The current node is always removed from the top (back) of the stack, ensuring depth-first traversal.

Point 3 — Visited tracking: check and mark (valid range: 0–20)
  Each node is checked against the visited collection before being processed, and added to visited when processed, preventing duplicate entries and infinite loops.

Point 4 — Neighbour push (valid range: 0–20)
  All unvisited neighbours from graph[current] are pushed onto the stack. For iterative implementations, neighbours are pushed in reverse adjacency list order so that they are popped and visited in forward order.

Point 5 — Overall correctness (valid range: 0–20)
  The method returns all reachable nodes from start in correct DFS order for all valid directed graphs.
