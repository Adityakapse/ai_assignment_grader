Calculate the asymptotic worst case running time of the functions below, as a function of the side length N of the input matrix `mat` (which is N x N).

- You can use the Theta notation or the big-O notation with tight bounds.
- Your analysis should refer to line numbers.

def f(mat):
    n = len(mat)
    s = 0
    for i in range(n):
        for j in range(i, n):
            s += mat[i][j]
    t = g(mat)
    return s + t

def g(mat):
    n = len(mat)
    t = 0
    for i in range(n):
        t += mat[i][i]
    return t

SAMPLE SOLUTION:
Let N be the side length of the matrix mat (mat is N x N).

Method f
Part A: n = len(mat); s = 0 - constant time.
Part B (nested loops over i, j): inner loop runs from j = i to N-1.
Part C: t = g(mat); return s + t - one call to g plus constant work.

Parts A and the return in Part C are Theta(1).

Part B (nested loops):
- Iterations: for each i the inner loop runs N - i times. Total = N + (N-1) + ... + 1 = N(N+1)/2 = Theta(N^2).
- Cost per iteration: Theta(1) - one matrix access and one += assignment.
- Total cost of Part B: Theta(N^2) x Theta(1) = Theta(N^2).

Part C:
- The call g(mat) costs Theta(N) (see g below); the addition and return are Theta(1).
- Total cost of Part C: Theta(N).

Overall running time of f:
Theta(1) + Theta(N^2) + Theta(N) = Theta(N^2).

Method g
Part D: n = len(mat); t = 0 - constant time.
Part E (for loop along the diagonal): single loop over i = 0..N-1.
Part F: return t - constant time.

Parts D and F are Theta(1).

Part E:
- Iterations: the loop runs from i = 0 to N-1, giving Theta(N) iterations.
- Cost per iteration: Theta(1) - one matrix access mat[i][i] and one += assignment.
- Total cost of Part E: Theta(N) x Theta(1) = Theta(N).

Overall running time of g:
Theta(1) + Theta(N) + Theta(1) = Theta(N).

STUDENT SOLUTION:
f has two nested loops and then calls g. The setup statements outside the loops are constant.

The nested loops sweep over part of the matrix; together they run Theta(N^2) times since it is essentially a double loop on an N x N matrix. Each iteration just reads a matrix entry and accumulates into s, which is Theta(1). So the nested loops cost Theta(N^2) * Theta(1) = Theta(N^2).

f then calls g, which adds some cost from g.

g has a single for loop that runs Theta(N) times (along the diagonal). Each iteration is Theta(1) since it just reads one matrix entry and adds. So g's loop is Theta(N) * Theta(1) = Theta(N).

Overall, g is Theta(N) and f is Theta(N^2).
