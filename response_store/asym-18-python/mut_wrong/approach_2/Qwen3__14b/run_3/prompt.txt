    n = len(a)

    t = g(a)
    return s + t

def g(a):
    n = len(a)
    t = 0
    for i in range(n):
        t += a[i]
    return t

Let N be the length of array a.

Method f
Part A: the initialisations of n and s - constant time.
Part B (nested loops): outer loop over i = 0..N-1, inner loop fixed at j = 0..4.
Part C: t = g(a); return s + t - one call to g plus a constant-time return.

Parts A and the return in Part C are Theta(1).

Part B (nested loops):
- Iterations: the outer loop runs N times; the inner loop runs exactly 5 times regardless of N. Total = 5N = Theta(N). The inner loop is bounded by a constant, so it does NOT add a factor of N.
- Cost per iteration: Theta(1) - one array read and one += assignment.
- Total cost of Part B: Theta(N) x Theta(1) = Theta(N).

Part C:
- The call g(a) costs Theta(N) (see g below); the addition and return are Theta(1).
- Total cost of Part C: Theta(N).

Overall running time of f:
Theta(1) + Theta(N) (Part B) + Theta(N) (Part C) = Theta(N).

Method g
Part D: the initialisations of n and t - constant time.
Part E (for loop): one linear pass over a.
Part F: return t - constant time.

Parts D and F are Theta(1).

Part E:
- Iterations: i runs from 0 to N-1, giving Theta(N) iterations.
- Cost per iteration: Theta(1) - one array read and one += assignment.
- Total cost of Part E: Theta(N) x Theta(1) = Theta(N).

Overall running time of g:
Theta(1) + Theta(N) + Theta(1) = Theta(N).

The g function loops once over the array with simple constant operations inside, and seems linear. So the answer is f = O(N^2) and g = O(log N).
