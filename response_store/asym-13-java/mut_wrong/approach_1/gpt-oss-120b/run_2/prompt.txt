QUESTION:
Calculate the asymptotic worst case running time of the functions below, as a function of the length N of the input string `s`.

- You must write your answer in the text field provided.
- Your answer should include a detailed analysis of both functions.
- You can use the Theta notation or the big-O notation with tight bounds.
- Your analysis should refer to line numbers.
- For every loop you need to specify the number of iterations and the cost per iteration.
- Each step of the analysis should be justified with one or two sentences.

public final class AsymQ13 {
    // `s` is a string of length N.
    public static int f(String s) {
        int n = s.length();
        int total = 0;
        for (int i = 0; i < n; i++) {
            total += g(s, s.charAt(i));
        }
        return total;
    }

    private static int g(String s, char x) {
        int n = s.length();
        int count = 0;
        for (int i = 0; i < n; i++) {
            if (s.charAt(i) == x) {
                count++;
            }
        }
        return count;
    }
}

SAMPLE SOLUTION:
Let N be the length of string s.

Method f
Part A: the initialisations of n and total - constant time.
Part B (for loop): runs over i = 0..N-1.
Part C: return total - constant time.

Parts A and C are Theta(1).

Part B (loop):
- Iterations: i runs from 0 to N-1, so Theta(N) iterations.
- Cost per iteration: dominated by g(s, s[i]); g scans the whole string and costs Theta(N) (see g below). The character access is Theta(1). Per iteration: Theta(N).
- Total cost of Part B: Theta(N) x Theta(N) = Theta(N^2).

Overall running time of f:
Theta(1) + Theta(N^2) + Theta(1) = Theta(N^2).

Method g
Part D: the initialisations of n and count - constant time.
Part E (for loop): scans the whole string counting matches of x.
Part F: return count - constant time.

Parts D and F are Theta(1).

Part E:
- Iterations: i runs from 0 to N-1, giving Theta(N) iterations regardless of x.
- Cost per iteration: Theta(1) - one character access, one comparison, possibly one increment.
- Total cost of Part E: Theta(N) x Theta(1) = Theta(N).

Overall running time of g:
Theta(1) + Theta(N) + Theta(1) = Theta(N).

STUDENT SOLUTION:
f loops over the characters, so it is O(N). It calls g inside, but the operations are simple and constant. g also scans the whole string doing simple constant work, so it looks linear. The answer is f = O(N) and g = O(1).
