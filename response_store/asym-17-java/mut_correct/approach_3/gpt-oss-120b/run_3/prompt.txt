Calculate the asymptotic worst case running time of the functions below, as a function of the side length N of the input matrix `mat` (which is N x N).

- Each step of the analysis should be justified with one or two sentences.

public final class AsymQ17 {
    // `mat` is N x N. Your analysis should be based on N.
    public static int f(int[][] mat) {
        int n = mat.length;
        int s = 0;
        for (int i = 0; i < n; i++) {
            s += mat[i][0];
        }
        int t = g(mat);
        return s + t;
    }

    private static int g(int[][] mat) {
        int n = mat.length;
        int t = 0;
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                t += mat[i][j];
            }
        }
        return t;
    }
}
